# Build your twins

Prompt used:

```text
Use Twinzies. I'm building an app for organizing physical media (discs, records, games). Build 4 to 12 twins from public discussion (Reddit mirrors, forums, reviews). Name them, cite evidence, label confidence, and keep everything as hypotheses.
```

What came out (see `physical-media-example/`):

- `twins/*.md`: six named twins, each with goals, pain points, vocabulary, tasks, accessibility context and a changelog
- `evidence-log.md`: the public sources behind them, paraphrased, no usernames
- `index.md`: who covers which need, and which audiences are not covered yet
- `avatars/*.svg`: line-art portraits, no props, varied head angles (archetypes, not evidence)

To extend: ask `Use Twinzies. I'm starting a [new product]. Show a reuse / adapt / new plan from my library.`
