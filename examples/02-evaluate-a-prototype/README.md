# Evaluate a prototype with twins

`shelf-prototype.html` is a tiny media-shelf prototype. All six twins walked it.

```text
Use Twinzies. Evaluate shelf-prototype.html with my six twins across functionality, language, visual design, UI, hierarchy and accessibility. Rate severity, say what you observed vs inferred, and list what you could not test.
```

Outputs: `report.html` (open in a browser) and `findings.json` (19 findings: 2 blocker, 12 major, 5 minor). Note the report's *Not run* list: screen readers, real devices and real users were not tested, and the report says so.
