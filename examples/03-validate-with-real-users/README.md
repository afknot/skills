# Validate with real users (like a UX researcher)

Twins give you hypotheses. Real people settle them. Use these prompts in order (full text in `../prompts.md`):

1. **Level 9, validation plan.** Turn the top insights into research questions, pick a method per question (in-product micro-survey, think-aloud, screener + interview), and get a screener, script and consent note.
2. **Run the sessions yourself.** Twinzies never fabricates participants.
3. **Level 10, log results.** Paste notes; each insight is marked confirmed, contradicted or unclear, and twin status updates (hypothesis to corroborated to validated).
4. **Level 11, decide.** Review each solution in chat: do it, backlog or dismiss.

Sample micro-survey to deploy in a product:

```text
Quick question: what were you trying to do just now? [free text]
How easy was it? [1-5]   What almost stopped you? [free text]
```
